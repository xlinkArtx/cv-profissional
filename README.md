# CV Profissional — Fase 1
Frontend React+TS+Vite+Tailwind, Firebase Auth/Firestore, 60 modelos (6 secções x 10).
1. Copia `.env.example` para `.env` e preenche (configuração Web do Firebase).
2. `npm install` → `npm run dev`.
3. Firestore: usa as regras actuais (users/{uid}/cvs/{cvId}). Não as tornes públicas.
Pendente: PDF final, pagamentos M-Pesa/e-Mola (Cloud Functions), dashboard, admin.
Novo modelo: adiciona uma entrada em `src/templates/registry.ts`.
